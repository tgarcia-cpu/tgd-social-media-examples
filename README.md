# Finder Portfolio

A responsive static portfolio with Icon, List, Column, and Gallery views. Open index.html to run it locally. The site uses relative paths and has no build dependencies.

## GitHub Pages

1. Unzip the download and upload its contents to the root of your repository. Keep index.html at the top level.
2. In Settings → Pages, choose Deploy from a branch. Select the branch containing the files and the /(root) folder. Save.
3. Open the website URL shown in Pages after deployment finishes.

## Customize

Edit projects.js to change the project names, folder assignments, and image descriptions. Each file field corresponds to an image in assets with a .webp extension. Replace the four concept previews with final project artwork before release. Set contactEmail to a public address to show the Contact link.

The original pointer.svg is included. cursor.svg uses the same geometry with a 22 × 13 viewport for browser cursor support.
